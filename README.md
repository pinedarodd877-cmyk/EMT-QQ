### 🔄 双重身份 · 秒切 QQ 号实现原理

#### 架构总览

```
┌─────────────┐        ┌──────────────┐        ┌─────────────┐
│  NapCat A   │◄──────►│              │◄──────►│  NapCat B   │

│  老号 QQ1   │        │   客户端     │        │  新号 QQ2   │
└─────────────┘        └──────────────┘        └─────────────┘
                              │
                              │ http 8899
                              ▼
                     ┌────────────────┐
                     │ server-proxy   │

                     └────────────────┘
```

#### 核心原理：双连接 + 身份路由

| 环节 | 机制 |
|---|---|
| **双 WS 连接** | 同时挂载两个 NapCat 的 WebSocket（8084 + 3001），各自独立收发 |
| **身份标记 acc** | 每条消息 / 每次 API 调用都携带 `acc`（0=老号，1=新号） |
| **发送路由** | `sa2()` 按 acc 选择对应 WS 发出，切换身份 = 换发送出口 |
| **身份存储** | `siA/snA`、`siB/snB` 双份变量 + `curAcc` 记录当前身份 |
| **界面联动** | 头像、昵称、标题随 curAcc 实时切换，毫秒级 |

#### 双连接核心代码

```javascript
// 账号 A（老号）：WS 8084
ws = new WebSocket('ws://127.0.0.1:8084?access_token=...');
ws.onmessage = function(ev){ hm(JSON.parse(ev.data), 0); };  // acc = 0

// 账号 B（新号）：WS 3001
w2 = new WebSocket('ws://127.0.0.1:3001?access_token=...');
w2.onmessage = function(ev){ hm(JSON.parse(ev.data), 1); };  // acc = 1
```

#### 发送路由核心代码

```javascript
function sa2(a, p, e, acc){
  var sock = acc === 1 ? (w2 || ws2 || null) : (ws || ws1 || null);
  if (!sock || sock.readyState !== 1) return;
  sock.send(JSON.stringify({ action: a, params: p || {}, echo: e || (a + '_' + Date.now()) }));
}
```

#### 身份切换核心代码

```javascript
function accSwitch(){
  var na = curAcc === 0 ? 1 : 0;          // 取反 = 切换
  if (na === 1 && cc && cc.type === 'g' && !isSharedGroup(cc.id)) {
    to('该群只有账号1在，无法切换');        // 共同群限制
    return;
  }
  curAcc = na;                             // 换身份
  si = na === 1 ? siB : siA;               // 换自己的QQ号
  accSyncUi();                             // 换头像/昵称/标题
}
```

#### 三个关键技术点

1. **消息去重**：群消息会被两个 NapCat 各推一次，用"内容签名 + 时间戳"去重；自己消息的回显用 `_selfMerge` 合并，不重复显示
2. **共同群限制**：`isSharedGroup()` 取两个账号群列表交集，只有共同群才能切换身份发送
3. **账号标识**：每条自己发出的消息打上 `acc` 标签，渲染时显示对应账号昵称（主题色），一眼分清谁发的
